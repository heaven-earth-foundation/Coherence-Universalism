# Distribution 0.10.1 engineering record

These files record the actual input checks, non-destructive numerical reproduction, source-content comparison and PDF-quality checks. equation_rendering_findings.json records the failed Word-conversion attempt; those error-bearing PDFs are not published. publication_pdf_quality_report.json refers to the final source-based PDFs. Absolute temporary paths in logs are provenance only, not supported user commands. The publication build instructions are in reader-build/README.md at the repository root.
