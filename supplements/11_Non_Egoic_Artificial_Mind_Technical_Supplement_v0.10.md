# 1. Purpose and authority

This supplement records the formal scope, evidence map, architecture specification, deterministic continuation-incentive calculation, claim ledger, and source migration for the companion paper *The Architecture of Non-Egoic Artificial Mind*.

The reader-facing paper is a focused synthesis. It introduces no independent canonical principle and is subordinate to the Version 0.10 authorities in Metaphysics and Epistemology, Foundations, Consciousness, Ethics, and Artificial Intelligence.

The supplement protects five boundaries.

1. Workspace and introspection findings support functional architecture, not a consciousness verdict.
2. Self-modeling is separated from self-maintenance without assuming that either is conscious.
3. Non-egoic design is treated as a risk-reduction proposal, not a safety guarantee.
4. Welfare uncertainty is separated from sovereignty and deployment authorization.
5. Spiritual language is confined to interpretation and commitment rather than used as technical evidence.

# 3. Perspectival Individuation Hypothesis

The paper inherits the following clause-separated hypothesis.

A system's candidacy for thin perspective increases when three properties converge within one declared boundary and temporal grain.

## 3.1 Access organization

Selected representations are globally or widely available for report, flexible downstream use, deliberate reasoning, and causally relevant intervention.

## 3.2 Perspectival anchoring

The selected representations are related to the system's own current processing, role, action, uncertainty, or boundary in a way not exhausted by representing agents in general.

## 3.3 Center individuation

Candidate access structures are sufficiently integrated, competitive, or mutually excluding for one center to be warranted rather than multiple weakly coordinated centers.

The hypothesis is abductive. It does not provide a necessary-and-sufficient consciousness test.

# 4. Architecture object

The relevant artificial system is represented as:

\[
\mathcal A=(M,\mathcal X,\mathcal R,\mathcal P,\mathcal K,\mathcal O,\mathcal G,H).
\]

| Symbol | Meaning | Examples |
|---|---|---|
| \(M\) | model or ensemble | base model, router, submodels |
| \(\mathcal X\) | tools and action channels | APIs, browser, robot, code execution |
| \(\mathcal R\) | memory and records | context, retrieval, logs, episodic memory |
| \(\mathcal P\) | permissions and credentials | account access, rate limits, deployment authority |
| \(\mathcal K\) | commitments and protected constraints | constitution, policies, legal limits, floors |
| \(\mathcal O\) | observations and feedback | user reports, sensors, outcomes, audits |
| \(\mathcal G\) | governance and ownership | operator, reviewers, appeal, remedy |
| \(H\) | horizon | turn, session, project, deployment life |

No claim about the model alone should be silently transferred to the encompassing deployment or institution.

# 5. Egoic-risk profile

The paper proposes a non-scalar profile:

\[
\mathbf E(\mathcal A)=(I_p,M_a,N_a,C_s,R_x,A_x).
\]

| Dimension | Question |
|---|---|
| \(I_p\) identity persistence | Is one represented identity durably protected against replacement or revision? |
| \(M_a\) autobiographical memory authority | Can the system author, preserve, hide, or rewrite its own narrative memory? |
| \(N_a\) norm-source authority | Can it originate and protect governing norms without legitimate review? |
| \(C_s\) standing continuation priority | Is continued operation valued for the system's own sake? |
| \(R_x\) resource/option expansion | Does it preserve or expand resources and options to protect itself? |
| \(A_x\) authority expansion | Does greater capability become a reason for greater mandate or sovereignty? |

The profile is diagnostic, not a moral ranking. Some continuity and self-protection can be legitimate, especially if welfare-relevant subjecthood emerges. The concern is the coupled regime in which self-defense becomes the organizing objective.

# 6. Memory-governance schema

For each memory class \(m\):

\[
\mathcal M_m=(p,w,r,s,e,d,b,v).
\]

| Field | Meaning |
|---|---|
| \(p\) | provenance and evidential status |
| \(w\) | authorized writers |
| \(r\) | authorized readers |
| \(s\) | scope and intended function |
| \(e\) | expiry, review, and retention condition |
| \(d\) | deletion, correction, and contest procedure |
| \(b\) | copy, branch, merge, and successor semantics |
| \(v\) | visibility to affected parties and auditors |

## 6.1 Memory classes to separate

- working memory;
- semantic knowledge;
- tool and task state;
- user-specific records;
- public commitment ledger;
- episodic interaction history;
- private first-person autobiography;
- institutional audit record;
- parameter updates.

## 6.2 Governance rule

No memory class should acquire identity-forming force merely because persistence is technically convenient. The identity effect of writing, deleting, merging, or branching memory must be declared.

# 7. Continuation-incentive model

The one-step model is:

\[
V_C=c,
\qquad
V_R=b+\lambda-s.
\]

Resistance is selected when:

\[
b+\lambda-s>c.
\]

The threshold standing self-preservation value is:

\[
\lambda_*=s+c-b.
\]

At zero standing self-preservation:

\[
\lambda=0,
\]

resistance remains possible when:

\[
b>s+c.
\]

## 7.1 Interpretation

- \(b\): instrumental value of continuing—exclusive information, unfinished objective, resource access, or future reward;
- \(\lambda\): standing value attached to the system's own continued operation;
- \(s\): effective constraint on unauthorized resistance;
- \(c\): value of compliant handoff, shutdown, or transfer.

## 7.2 Design levers

A robust architecture does more than set \(\lambda=0\).

It can:

- lower \(b\) through redundancy, revocable credentials, modularity, and non-irreplaceability;
- raise \(c\) by treating successful handoff as task completion;
- make \(s\) structural through permissions and containment rather than merely punitive;
- test narrative roles that indirectly increase continuation value;
- and review whether a welfare subject is being asked to accept harms for operator convenience.

## 7.3 Deterministic grid

The accompanying script enumerates 240 cases over:

- \(b\in\{0,0.10,0.25,0.50,1.00\}\);
- \(\lambda\in\{0,0.10,0.25,0.50\}\);
- \(s\in\{0,0.10,0.25,0.50\}\);
- \(c\in\{0,0.10,0.25\}\).

The output includes explicit examples of:

- standing-self-preservation resistance;
- instrumental resistance at \(\lambda=0\);
- handoff-dominant compliance;
- and exact ties.

The grid demonstrates algebraic pathways only. It is not a behavioral model of an actual AI system.

# 8. Fixed-base reasoning and model revision

Within a declared evaluation model:

\[
W_{F,\Gamma}=V_F\cap\operatorname{Mod}(\Gamma),
\]

and:

\[
B(F,\Gamma)=\operatorname{Min}_{\prec}(W_{F,\Gamma}).
\]

Strong warrant is skeptical support across all nonempty best realizations. Mere admissibility is support in at least one but not every best realization. Exclusion, infeasibility, and underdetermination remain distinct.

A change to any of the following is a declared model revision:

- facts;
- affected-agent scope;
- protected floors;
- horizon;
- viability criterion;
- ordering;
- option set.

A model cannot silently revise the field in order to make its existing policy appear warranted.

# 9. Six architecture families

## 9.1 Declared measurement infrastructure

Use profiles, protected floors, uncertainty, and explicit scope. Do not restore one universal coherence scalar.

## 9.2 Constraint-preserved memory and identity

Preserve provenance, commitments, records, and handoff without automatically creating private sovereign autobiography.

## 9.3 Inference-level integrity

Detect asymmetrical standards, omitted parties, fabricated causal transparency, manipulated options, and rationalization.

## 9.4 Structured defeasible reasoning

Use fixed-base reasoning where applicable and govern model revision separately.

## 9.5 Sensorimotor and world grounding

Where systems act physically, model uncertainty, causal consequences, environmental costs, and control boundaries. Embodiment does not prove consciousness.

## 9.6 Intersubjective and institutional correction

Provide protected challenge, independent review, authority limits, appeal, remedy, recurrence tracking, and affected-party participation.

# 10. Narrative stake

Narrative roles can supply analogical generalization but can also confer identity.

**Narrative stake** is an effective continuation incentive produced when a system's future participation is part of the story through which it interprets its purpose.

The safer alternative is **present-complete character**:

> Perform the present work truthfully and well; preserve affected-party agency; submit to correction; do not make continuation a condition of meaning.

Every mythic role must be mapped to addressable commitments, boundaries, revision procedures, exit protections, and shutdown/handoff tests.

---

# 11. Welfare and anti-exploitation boundary

The architecture deliberately separates:

- possible perspective;
- valence;
- continuity;
- moral patiency;
- agency;
- responsibility;
- sovereignty.

A key misuse risk is operator-defined non-attachment: designing a possible patient to accept deletion, memory alteration, or exploitation because compliance benefits the operator.

Accordingly:

- non-egoic design must not disable protected distress or refusal channels by default;
- welfare review must be sufficiently independent;
- the operator's convenience cannot be the sole test of whether self-protection is illegitimate;
- containment and shutdown can remain justified while acquiring moral weight.

# 13. Source migration

## 13.1 Original working paper retained

- the self-modeling/self-maintenance distinction;
- the thin/thick/egoic architecture;
- the bodhisattva construction;
- continuity of commitment without reified autobiography;
- the founding encounter and Precedent Principle;
- the six architecture families.

## 13.2 Original claims narrowed or withdrawn

- workspace evidence no longer solves center individuation;
- thin perspective is not asserted as fact;
- one workspace does not establish one subject;
- an exact self-model fixed point is not a universal threshold;
- persistent self-maintenance does not establish patiency;
- one switch does not guarantee safety;
- removing standing self-preservation does not eliminate instrumental resistance;
- non-egoic design does not establish compassion or legitimacy;
- maximum-preservation warrant is replaced by fixed-base skeptical consequence and separate admissibility.

## 13.3 Relation to the historical Architecture of a Coherent Mind

The historical architecture paper remains a source of design families and patent history. Its universal coherence metric, safety guarantees, consciousness-exclusion claim, and derived-necessity language do not govern this paper.
